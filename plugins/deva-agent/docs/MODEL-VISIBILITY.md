# 模型列表的可见性

0.8.34 将桌面默认模型与候选列表放在模型页表单的前部，地址、Key 和长度编辑在后。
完整 provider JSON、文件 stat 与 RPC 诊断保留在「配置来源与诊断（展开可复制）」中；
候选列表前不再重复展开这些 JSON。获取模型列表读取桌面配置，刷新远端模型列表才访问远端。
本地列表与远端刷新失败互不排斥。

真实 Studio 0.8.30 的 8648 页面中，0.8.33 的 iframe 高 697px；列表初始 top=1799.92px，
点击获取后仍为 top=882.92px。RPC 成功且有一个 option，展开的配置/诊断把候选推出视口。
这是插件的内容顺序问题；无须更改宿主 iframe 或网络批准策略。

采集只观察元数据。监听器安装、MutationObserver、几何查询、事件命中、日志 RPC 失败都
不能阻断业务 UI 或清理。先创建顶部状态，再安装可失败的采集器，最后挂载表单。
真实业务错误仍通过状态与重试按钮展示，不把采集异常当作模型读取失败。

验收时同时记录实际路由、iframe rect、候选 rect、elementFromPoint 与截图。
DOM 有 option 或 RPC 返回成功单独都不构成可见性通过。测试中的故障注入仅验证异常隔离，
不能当作用户页面的测量证据。

0.8.35 清理正式设置页：成功后隐藏加载状态与重试，不再常驻版本、路径和内部计数。
配置原文与 RPC 诊断仅放在默认关闭的「配置来源与诊断」中；字段只保留 label，
不再为同一字段另加同文 h3。读取失败在表单顶部显示错误及「重试读取」，重试复用表单。
路径按服务端原文保留，`.deva` 中的点不删除；截图小字号应放大或以 DOM 原文核实。

0.8.36 按实际账号定位需求增加顶部小号版本标记（不含路径或调试计数）。
声明 http 能力，仅观察 GET /api/studio/plugins/deva/client 的响应，不改变头、正文或批准策略。
日志新增 userId/profile（宿主认证上下文）、endpoint（Host，不含query）、clientVersion、
clientSha256（实际source字节）、HTTP状态和字节数；匿名响应标记0/unauthenticated。
model-ui-trace 的账号/Profile 由服务端run.identity补入，客户端不能伪造这些字段。
日志落盘错误不影响资源下发。没有请求日志不能证明用户没有访问；旧缓存和请求未到此实例仍需实际页面证据。

0.8.37 顶部小字常驻显示版本、当前候选数及读取/刷新/失败阶段，0候选也有明确原因。
首次挂载后仅在已有候选越出视口时scrollIntoView(nearest)，采样/滚动异常仍由observeSafely隔离。
`scripts/model-ui-selfcheck.ps1` 为Windows只读自检，检查宿主环境变量指定目录及默认用户目录，
输出安装版本、客户端SHA256和白名单事件字段，不读取配置或凭据。找不到目录会列出查找位置，
不推断插件未安装。历史版本目录不代表当前运行版本；Windows执行尚需实际设备验证。
