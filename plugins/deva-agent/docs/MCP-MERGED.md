# MCP 合并与同步

设置页只调用一次 get-mcp-servers、渲染一个服务容器。页面与 Agent 均通过 mcp-merged 提供的 host 适配器读取有效清单，不再叠加 run.mcpServers 或桌面只读列表。

- 共享目录仅 sharedDevaUserId 指定用户可用；未配置时使用插件激活用户。其他用户仍使用自身宿主目录，不读取或写共享文件。
- 桌面 mcpServers 的键是稳定 id。宿主 name 去除首尾空白后优先按 id 匹配，再按唯一的桌面 name 匹配；大小写保留（两端名称区分大小写），歧义显示名不猜测。匹配后只返回桌面 id，宿主操作反向映射回 name。
- 宿主独有条目补入 mcpServers，同时补 name、transport 供桌面读取。streamable_http 映射 http；启用态写 config.json 的 mcp.enabled。已有桌面条目及启用态优先，不因读取覆盖；桌面独有服务直接通过插件客户端连接，不向会裁剪字段的宿主创建有损副本。
- 启用态缺省为 false；Agent 未保存勾选时使用启用服务，保存空数组表示全部不连接。勾选只影响当前账号/Profile。
- 详情仅投影 type/command/args/env/url/headers/enabled；env/headers 返回掩码。编辑在完整原记录上合并，保留未知字段，掩码保留原值，null 删除单个凭据。无法在表单编辑的字段可继续由桌面修改。页面不显示来源标记或额外列表。
- 对已有宿主记录，页面编辑同步宿主可表达字段；非字符串 env/headers 时只同步启用态，完整配置留在桌面。宿主独有服务的创建先经宿主校验再写桌面。删除同步删除两端记录。
- secretRef/非字符串 env/headers 不强制转换、不丢弃；当前 MCP 客户端没有通用桌面密钥解引用能力，会报告该服务不可用，其余服务继续连接。可用字符串或 ${VAR} 连接。未知字段保留不代表客户端实现其语义。
- 每文件写前备份到同目录随机 .bak；临时文件 fsync 后 rename，保留原 mode/uid/gid；内容相同不写。拒绝坏 JSON、非法结构、链接文件，rename 前比较原文，异常清理临时文件。现有条目对象内容不变；首次新增时 JSON 文件排版会规范化，后续无变化则字节完全不变。
- 这是缺项对齐与本页 CRUD 同步，不是后台文件监听。桌面已有条目优先，因此宿主外部编辑同名配置不会自动覆盖桌面；桌面外部删除但宿主仍有的条目在下一次读取时会补回。
- 宿主 API、mcp.json、config.json 不具备跨系统事务。中途失败可能一端已写，错误明确返回；跨进程检查与 rename 间仍有竞争窗口，尚未验证并发写。桌面已打开时的内存缓存需重载。
- 工具命名空间归一化发生冲突时显式报告并跳过冲突项，避免连接池同名覆盖；不会静默覆盖工具。
